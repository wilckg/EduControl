# EduControl v1.0 — Etapa 5.1 (visual de teste)

Esta versão é uma adaptação visual experimental da Etapa 5.

## Alterações
- Logos reais no rodapé institucional.
- Background experimental no login com a fachada da Fábrica de Programadores.
- Ajustes visuais no layout autenticado (sidebar, cards e topo).
- Não altera rotas, permissões nem estrutura de banco de dados.

## Observação
Esta não é a versão visual definitiva. O objetivo é apenas validar aparência e legibilidade.
