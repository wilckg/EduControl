# Logos oficiais (a fornecer)

Coloque aqui os arquivos institucionais aprovados, mantendo estes nomes:

- `fabrica-de-programadores.png`
- `prefeitura-santana-de-parnaiba.png`
- `senai-sp.png`

Use PNG transparente, preferencialmente 2x a altura de exibição, e preserve a proporção original.
Sem esses arquivos, o rodapé mostra iniciais neutras (não são logomarcas oficiais).
Não altere a ordem definida no componente `src/InstitutionalFooter.tsx`.
